# Paper assets

This directory is intentionally restricted to presentation-ready evidence for
the active TopoNav Harness paper.

- `figures/`: architecture, main result, and paired qualitative evidence;
- `tables/`: paper-facing CSV summaries;
- `videos/`: actual Habitat-GS execution replay.

See `INDEX.md` for the role and interpretation boundary of every retained
asset. Raw results and historical experiment data belong under `outputs/`, not
in this directory.
