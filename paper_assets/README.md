# Paper assets

This is the headless-server handoff directory. Only presentation-ready
artifacts belong here. Read `INDEX.md` before using an asset in a paper or
group meeting: it labels each artifact as current-paper, motivation-only,
archived, or internal sanity evidence.

- `tables/`: final CSV tables with one row per method/setting;
- `figures/`: paper-quality PNG/SVG figures;
- `videos/`: short group-meeting or paper videos.

Raw caches, checkpoints, manifests, and per-episode logs remain under
`outputs/formal/` and must not be deleted. Historical S0--S2, B1, C1, G1 and
GeoAnchor assets are retained but are not evidence for the active paper.
Active-paper outputs use the `failure_aware_p1_` prefix and are listed in the
index rather than mixed with historical figures.
