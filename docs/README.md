# Documentation map

- `RESEARCH_CONTRACT.md`: immutable scientific direction and exclusions.
- `MODEL_SPEC.md`: authorized WorldFlow model boundary; not an implementation
  request by itself.
- `BENCHMARK_SPEC.md`: formal benchmark protocol and evaluation contract.
- `exec-plans/active/`: exactly one authorized task plan.
- `exec-plans/completed/`: closed plans with accepted evidence.
- `results/`: durable result summaries, including limitations.

Read documents by role; do not use this directory as an invitation to invent a
new research direction.
