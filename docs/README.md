# TopoNav Harness documentation

This directory contains only the active paper contract and its current static
Habitat-GS evidence.

## Source of truth

- `RESEARCH_CONTRACT.md`: scientific question, contribution boundary, and
  exclusions.
- `MODEL_SPEC.md`: semantic-topology context, tool protocol, validator,
  executor, and feedback interfaces.
- `BENCHMARK_SPEC.md`: paired static benchmark and metric contract.
- `exec-plans/active/TOPONAV_HARNESS_P1.md`: the single authorized execution
  plan.

## Current evidence

- `results/TOPONAV_P1_STATIC_RESULTS.md`: paper-facing quantitative result,
  task breakdown, integrity notes, and limitations.
- `presentations/GROUP_MEETING_TOPONAV_P1.md`: concise group-meeting narrative
  and anticipated questions.

Historical code, raw results, and experiment data remain in Git history and
`outputs/`. Obsolete research contracts and reports are intentionally excluded
so agents cannot mistake an archived direction for the active paper.
